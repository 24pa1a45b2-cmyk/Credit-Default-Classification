# Credit Default Classification – Data Analysis

## Project Description
This project focuses on analysing a credit default dataset using Python.

The main aim is to understand customer information and identify patterns related to loan defaults.

## Dataset
The dataset contains customer details such as:
- Age
- Loan Amount
- Credit Score
- Home Ownership
- Income
- Loan Purpose
- Number of Open Accounts
- Default Status

## Project Steps
1. Data Collection
2. Data Understanding
3. Data Preprocessing
4. Handling Missing Values
5. Removing Duplicate Records
6. Correcting Categorical Values
7. Univariate Analysis
8. Bivariate Analysis
9. Multivariate Analysis

## Tools and Libraries Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Conclusion
This project helped us understand the credit default dataset, clean the data, and analyse relationships between different customer details and loan default status.
